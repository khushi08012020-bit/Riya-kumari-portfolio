IdentiPI – Privacy-First KYC dApp

IdentiPI addresses the critical vulnerability in traditional KYC where centralized servers store unencrypted sensitive identity proofs (passport, national ID, SSN), leading to massive recurring identity theft and data leaks.

Technical Architecture & Stack:

  • Midnight (ZKP): Employs Zero-Knowledge Proof cryptographic circuits to prove identity compliance criteria without exposing raw credentials.
  • Veridian (DID): Generates Decentralized Identifiers, empowering users with sovereign digital credential ownership.
  • IPFS: Content-addressed, decentralized interplanetary file system used for resilient encrypted verification metadata storage.
  • Strands SDK: Streamlined smart orchestration layer interfacing cryptographic state transitions.
  • React & Node.js: Intuitive responsive front-end coupled with backend validation and RPC relays.
Key Engineering Accomplishment: Successfully designed selective disclosure logic that lets a user prove attributes like "Age ≥ 18" or "Jurisdiction Compliant" without revealing their real name, birthdate, or home address.
