# Riya Kumari - Modern Developer Portfolio

A modern, responsive, and performance-optimized personal portfolio website built with semantic HTML5, modern CSS3, Tailwind CSS, and Vanilla JavaScript.

## 🌟 Highlights & Features

- **Personalized Profile:** Built directly from Riya Kumari's resume featuring:
  - **Hero Section:** Dynamic typewriter effect displaying key specializations, live availability badge, quick contact links, and stat metrics (Top 100 Asia, 7.45 CGPA, etc.).
  - **About Section:** Narrative overview, key engineering strengths, quick-copy contact details, and location.
  - **Skills Section:** Categorized into Languages, Frameworks, Databases & Storage, and Web3 / AI & Cloud.
  - **Projects Showcase:** Detailed deep-dives into:
    - **FRAB** (Financial Risk Analysis & Behavioral Investigation &mdash; 3rd Prize Winner at Smart Horizon '26 48-hr Hackathon)
    - **IdentiPI** (Privacy-First KYC dApp &mdash; Cardano Hack Finalist Top 100 Asia)
    - **PrintX** (AI-Powered Autonomous Printing System with AWS Bedrock & Lambda)
    - Interactive modals with architectural breakdowns and direct GitHub repository links.
  - **Certifications & Trainings:** Timeline cards covering COMED KARES and Vtricks Technologies / Sambhram Institute programs.
  - **Education Journey:** Visual academic timeline with degree, institution, location, dates, and scores.
  - **Contact Section:** 1-click clipboard copy for email and phone number, direct LinkedIn & GitHub links, and pre-filled interactive email composer.
- **Theme Support:** Dark / Light mode toggle with smooth transitions and persistence via `localStorage`.
- **Zero Build Tools Required:** Pure static web standards. Open `index.html` in any browser to view instantly!

## 🚀 Quick Deployment Guide

### Option 1: GitHub Pages (Free)
1. Push this folder to a GitHub repository named `riya-kumari-portfolio` or `<username>.github.io`.
2. Go to repository **Settings** -> **Pages**.
3. Under **Branch**, select `main` (root) and click **Save**.
4. Your website will be live at `https://<username>.github.io/<repo-name>/`.

### Option 2: Vercel / Netlify
- Drag and drop this folder onto [Vercel](https://vercel.com) or [Netlify](https://netlify.com) for instant global edge deployment with custom domain support.
